So messen Sie Ihr Dach

  1. Luftbild laden. Ziehen Sie Ihre .tif-Datei ins Fenster oder klicken Sie auf „Datei auswählen". Die Datei bleibt auf Ihrem Gerät.
  2. Werkzeug wählen. Links auf Fläche messen, Länge messen oder Punkt setzen klicken.
  3. Auf dem Dach klicken. Setzen Sie nacheinander die Eckpunkte.
    • Fläche: Klicken Sie zum Abschluss wieder auf den ersten Punkt. Die Quadratmeter erscheinen sofort.
    • Länge: Mit einem Doppelklick beenden.
  4. Korrigieren. „Letztes rückgängig" entfernt die letzte Messung, „Alles löschen" leert die Karte.
  5. Speichern. Als PDF oder Als Bild für den Versand. Mit Arbeit sichern können Sie später weitermachen (dann dieselbe .tif erneut laden).
Tipp: Mit dem Mausrad zoomen, mit gedrückter Maustaste verschieben. Über dem Regler links unten können Sie eine Straßenkarte einblenden.
